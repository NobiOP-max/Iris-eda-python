# Iris Dataset - Exploratory Data Analysis

Exploratory data analysis on the classic Iris dataset using Python.

## Tools used
Pandas, NumPy, Seaborn, Matplotlib, scikit-learn

## What I did
- Inspected data shape, types, and summary statistics
- Checked for missing values and outliers using boxplots
- Applied label encoding and Min-Max normalization
- Visualized feature distributions and relationships (histograms, scatterplot, correlation heatmap)

## Key findings
- Petal length and width show a strong positive correlation
- These two features separate the three species fairly clearly
